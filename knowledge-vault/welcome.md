# Welcome to Your Personal Assistant Knowledge Vault

This is an Obsidian-compatible markdown vault that serves as the long-term memory for your Personal Assistant AI.

## Structure

- **Notes** - Any markdown files you create
- **Tags** - Use `#tag` in frontmatter or inline for organization
- **Links** - Use `[[wiki-links]]` to connect related notes
- **Frontmatter** - YAML metadata at the top of each note

## Tag Conventions

| Tag | Purpose |
|-----|---------|
| `#person` | People, contacts, relationships |
| `#preference` | Your preferences and settings |
| `#fact` | Verified facts and knowledge |
| `#project` | Active projects and tasks |
| `#reference` | Reference materials, docs |
| `#meeting` | Meeting notes |
| `#idea` | Ideas and brainstorming |
| `#goal` | Goals and objectives |

## Example Notes

See the other files in this vault for examples:
- `preferences.md` - Your preferences
- `projects.md` - Active projects

## Usage

The AI assistant can:
- Search this vault for relevant context
- Create new notes with `memory_create_note`
- Read existing notes with `memory_read_note`
- List all tags with `memory_list_tags`

All notes are plain markdown - you can edit them directly in Obsidian or any text editor.
