Download & launch Zoveli AI

Own hardware. Ten minutes. No account needed to start.

0. What you need

  • Node.js 22+, Python 3.11+, pnpm 11.7.0+, Git
  • Optional but recommended for verified math: a mathcore checkout next to this repo (pip install -e ../mathcore)

1. Windows (PowerShell)

winget install OpenJS.NodeJS.LTS Python.Python.3.11 Git.Git
npm install -g pnpm@11.7.0
git clone https://github.com/blessandy9104-hue/zoveli-ai.git
cd zoveli-ai
pip install -e ..\mathcore   # optional: enables verified math
pnpm install
pnpm run build
pnpm test                    # 70 unit tests, all green
pnpm start                   # launch the CLI assistant

2. macOS

brew install node@22 python@3.11 git
npm install -g pnpm@11.7.0
git clone https://github.com/blessandy9104-hue/zoveli-ai.git

3. Linux (Debian/Ubuntu)

sudo apt install -y nodejs python3 python3-pip git
npm install -g pnpm@11.7.0
git clone https://github.com/blessandy9104-hue/zoveli-ai.git
cd zoveli-ai

4. Launch it

pnpm start            # CLI — works fully offline
pnpm run web          # Web UI + API at http://127.0.0.1:3080
pnpm run desktop      # Electron shell (dev mode)

In the CLI, try: /math solve x^2 - 5x + 6 = 0 · /sys · /tools · /help

For open-ended chat, set DEEPSEEK_API_KEY — or point ZOVELI_API_BASE at any OpenAI-compatible endpoint such as local Ollama. No key needed for any local tool.

5. Log in (web UI)

Open http://127.0.0.1:3080/login and enter any email address — including @proton.me. Zoveli sends a 6-digit code (no password, no OAuth middleman). Without an SMTP server configured, the code prints to the server console (dev mode).
