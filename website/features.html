Features you can use today

Everything below runs from a local install — no cloud account required.

🔬 Verified mathematics

Solve, differentiate, integrate, linear algebra, number theory, logic, statistics, units — each result confirmed by independent methods with a sealed certificate. A governor routes to algebra, calculus, statistics, logic, units, and discrete specialists that memorize verified proofs and recall them later. Access: CLI /math, or mathcore_compute, math_algebra_solve, math_recall tools.

🧠 Local-first memory

A local SQLite knowledge store with wiki-links, tags, ranked full-text search, and a knowledge graph — mirrored as Markdown files you can open anywhere. Access: memory_create_note, memory_search, vault_search, vault_graph.

🎨 Five interface looks, your choice

Daylight, Midnight, Forest, and Sunset are pure-CSS themes that work fully offline; Unicorn adds an animated Unicorn Studio WebGL backdrop (loads only when picked). Smooth Lenis scrolling throughout, served vendored with native-scroll fallback.

💻 17 programming languages

Detection, complexity analysis, formatting, linting, test running, and tooling guides. Access: language_detect, language_analyze, language_format, language_lint, language_run_tests.

🖥️ System & hardware awareness

OS, CPU, memory, disk, GPU, battery, and network insight with budget checks before heavy jobs — all local, zero network calls. Access: sysinfo_snapshot, sysinfo_check.

⚡ Capability awareness

The assistant inventories its own 28 capabilities, adapts plans to what's available, and reports gaps. Access: capability_scan, capability_adapt, capability_report.

🛠️ Everyday tools

Code review, doc generation, project health scoring, smart scheduling, security scanning, workflows, subagents, and skills. Run /tools in the CLI or GET /api/tools for the live list (~51 tools).

🔑 Passwordless login

Email one-time codes for any inbox including @proton.me — no passwords, no OAuth middleman. Open /login in the web UI.

🖥️ Three ways to run

  • CLI — pnpm start, works fully offline.
  • Web UI + HTTP API — pnpm run web, chat, tools, login.
  • Desktop — pnpm run desktop, Electron shell around the local server.
