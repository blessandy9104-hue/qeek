qeek

The assistant that proves its math, owns your data, and knows its own capabilities.

GitHub Get started

Verified mathematics, not guesses

Every computation runs through mathcore: independent methods must agree before any value is released. Real output from this project:

$ mathcore "solve x^2 - 5x + 6 = 0"
VERIFIED  solve x^2 - 5x + 6 = 0 for x
    x = 2; x = 3
    confirmed by: sympy-solve, numeric-polynomial-roots,
                  check:exact-substitution, check:distinct-root-count
    certificate 9c8739cbf1e5ad80

Wrong answers are caught, not repeated: MISMATCH: the claim differs from the verified result.

Local-first by construction

  • Obsidian-compatible vault — your memory is plain Markdown files you own.
  • Offline math + tools — 38 local tools work with no API key and no network.
  • Passwordless login — email codes for any inbox including @proton.me. No passwords stored, no OAuth middleman.
  • Capability awareness — the assistant knows what it can do and says when it can't.

Quickstart

git clone https://github.com/blessandy9104-hue/qeek.git
cd qeek
pip install -e ../mathcore   # sibling checkout, provides mathcore-mcp
pnpm install                 # pnpm 11.7.0
pnpm run build
pnpm start                   # CLI — try: /math solve x^2 - 5x + 6 = 0

Checks every contributor runs: pnpm run lint · pnpm run typecheck · pnpm test · Playwright e2e across Chromium, Firefox, WebKit.

Architecture

  • qeek-host — plugin loader, tool registry, REPL, optional LLM chat (any OpenAI-compatible endpoint).
  • 55 plugins — agent, session, tools, workflows, subagents, LSP, sandbox, browser, terminal, skills, memory, 17-language tooling, system/hardware awareness, security scanner, telemetry.
  • Apps — CLI (working), Web UI + HTTP API (working), Electron desktop shell (working, unsigned).

Full docs live in the repo: docs/architecture.md, ADRs, runbooks, and API reference.
