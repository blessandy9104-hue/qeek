Verified mathematics, not guesses

Every computation runs through mathcore: independent methods must agree before any value is released. Real output from this project:

$ mathcore "solve x^2 - 5x + 6 = 0"
VERIFIED  solve x^2 - 5x + 6 = 0 for x
    x = 2; x = 3
    confirmed by: sympy-solve, numeric-polynomial-roots,
                  check:exact-substitution, check:distinct-root-count
    certificate 9c8739cbf1e5ad80

Wrong answers are caught, not repeated: MISMATCH: the claim differs from the verified result.

Local-first by construction

  • Obsidian-compatible vault — your memory is plain Markdown files you own.
  • Offline tools — ~39 local tools work with no API key and no network.
  • Passwordless login — email codes for any inbox including @proton.me. No passwords stored, no OAuth middleman.
  • Capability awareness — the assistant knows what it can do and says when it can't.

Run it on your hardware in minutes

git clone https://github.com/blessandy9104-hue/zoveli-ai.git
cd zoveli-ai
pnpm install && pnpm run build
pnpm start   # → /math solve x^2 - 5x + 6 = 0
