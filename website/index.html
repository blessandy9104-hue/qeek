Why not just use ChatGPT or Claude?

They are great — and $20/month, cloud-only, and they learn from what you type unless you opt out. Zoveli is built on the opposite bet:

Zoveli AIChatGPT / Claude
PriceFree, runs on your machine$8–$20+/month subscriptions
Your dataStays home — plain Markdown vault you own, never used for trainingSent to the cloud; training opt-out buried in settings
OfflineFully offline for ~39 local toolsRequires internet, always
MathVerified or withheld — independent methods must agree, sealed certificateBest-effort guesses, stated confidently
Model choiceAny API key, or free local Ollama — swap anytime, zero cost possibleLocked to one vendor's models

Use Zoveli when the work is yours: private notes, exact computation, and tools that must work on a plane.

Value in 30 seconds

$ git clone https://github.com/blessandy9104-hue/zoveli-ai.git
$ cd zoveli-ai && pnpm install && pnpm run build
$ pnpm start
zoveli — local-first assistant. Type /help for commands, /quit to exit.
zoveli> /math solve x^2 - 5x + 6 = 0
VERIFIED  x = 2; x = 3  (certificate 9c8739cbf1e5ad80)

Verified mathematics, not guesses

Every computation runs through mathcore: independent methods must agree before any value is released. Real output from this project:

$ mathcore "solve x^2 - 5x + 6 = 0"
VERIFIED  solve x^2 - 5x + 6 = 0 for x
    x = 2; x = 3
    confirmed by: sympy-solve, numeric-polynomial-roots,
                  check:exact-substitution, check:distinct-root-count
    certificate 9c8739cbf1e5ad80

Wrong answers are caught, not repeated: MISMATCH: the claim differs from the verified result.

Local-first by construction

  • Obsidian-compatible vault — your memory is plain Markdown files you own.
  • Offline tools — ~39 local tools work with no API key and no network.
  • Passwordless login — email codes for any inbox including @proton.me. No passwords stored, no OAuth middleman.
  • Capability awareness — the assistant knows what it can do and says when it can't.

Run it on your hardware in minutes

git clone https://github.com/blessandy9104-hue/zoveli-ai.git
cd zoveli-ai
pnpm install && pnpm run build
pnpm start   # CLI — works fully offline
pnpm run web # Web UI + API at http://127.0.0.1:3080
